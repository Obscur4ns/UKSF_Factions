# 1. Purpose

This document converts the Takistani Pashtu language standard into a usable project vocabulary.

It provides:

- the project-native spelling of Takistan;
- Pashtu names for government/security organisations;
- short forms suitable for patches and vehicles;
- common government/security terminology;
- common environmental/signage terminology;
- an initial male personal-name pool;
- an initial female personal-name pool;
- a neutral optional surname/byname pool;
- a fictional native Pashtu self-designation for NTEF;
- examples for future Arma identity configuration.

This is intended to be directly useful when creating:

```text
CfgWorlds identity pools
CfgVehicles identities
patches
vehicle textures
signage
mission briefs
intelligence documents
editor descriptions
```

---

# PART I — CONFIDENCE LEVELS

## 2. Terminology Status

Three labels are used.

### `ATTESTED`

The core wording is directly supported by normal Pashtu usage found in Pashtu-language reporting or institutional terminology.

### `UKSF CONSTRUCTION`

The wording is created for fictional Takistan using attested Pashtu grammatical/organisational patterns.

### `REVIEW BEFORE ART`

The form is suitable for project documentation/config planning but should receive fluent/native review before it is permanently rendered on a high-profile texture, emblem or sign.

---

## 3. Personal-Name Status

The personal-name pool is suitable for immediate use as an Arma identity/name pool.

However:

> The pool represents names usable in a Pashtu-speaking fictional setting, not an assertion that every listed name is uniquely or exclusively Pashtun.

Many personal names are shared across:

- Pashtu speakers;
- Dari speakers;
- neighbouring Muslim cultures;
- wider Arabic/Persian naming traditions.

This is realistic and desirable.

# PART II — COUNTRY NAME

## 4. Takistan

**English / established Armaverse:**

```text
Takistan
```

**Project native Pashtu spelling:**

```text
تکستان
```

**Operational romanisation:**

```text
Takistan
```

**Status:** `UKSF CONSTRUCTION`

No official Bohemia native-script spelling has been located.

`تکستان` is therefore the project-standard Pashtu-script rendering of the established fictional name.

Do not alternate between:

```text
تکستان
تاکستان
```

inside UKSF material.

Project standard is:

```text
تکستان
```

---

## 5. Takistani

For native prose, prefer grammatical constructions using:

```text
د تکستان ...
```

meaning approximately:

```text
of Takistan / Takistan's ...
```

rather than attempting to force an adjective into every phrase.

Where an adjectival form is required, project working form:

```text
تکستانی
```

Operational:

```text
Takistani
```

**Status:** `UKSF CONSTRUCTION / REVIEW BEFORE ART`

# PART XII — FACTION NAME POOLS

## 37. TNA / TNP / TBG

Use the complete personal-name pool.

Do not create separate "military" and "civilian" ethnic name sets unless a future lore reason appears.

This prevents the security forces from feeling culturally separate from the population they come from.

---

## 38. NTEF

Use the same normal personal-name pool.

Do not fill NTEF exclusively with:

- religious titles;
- Arabic noms de guerre;
- ominous aliases.

They are people from the same regional naming environment.

If an intelligence scenario needs an alias, define it individually.

---

## 39. Senior Leaders

A senior political/security figure may use:

```text
full personal name
+
role/title in briefing text
```

Example structure:

```text
Brigadier <Name>
Police Commander <Name>
Governor <Name>
```

Do not encode titles into the base name pool.
